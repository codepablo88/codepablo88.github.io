# Sitio personal — Pablo Escribano

Versión inicial del sitio personal inspirado en https://lucasramosvfx.com/.

Cómo ver localmente:

1. Abrir `index.html` en el navegador.

O, servir con Python desde la carpeta del proyecto:

```bash
# desde la carpeta c:/Users/Pablo/Documents/Repositorios/personal_web
python -m http.server 8000
# luego abrir http://localhost:8000
```

Archivos principales:

- index.html
- styles.css
- assets/avatar.svg

Personaliza los proyectos y textos en `index.html`.
