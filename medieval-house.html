02 / Technical breakdown

Sistemas

Cada módulo resuelve una parte concreta del edificio y comparte información con el resto para producir resultados coherentes.

01

Roof generation system

Tejados adaptativos

El sistema detecta los puntos de cumbrera a partir de la huella del edificio, construye planos con pendiente y combina las secciones. Después distribuye tejas con variación y añade envejecimiento procedural.

Adaptive by design

Cada sistema interpreta la geometría anterior. La casa puede cambiar de forma y el resto de elementos se reconstruye automáticamente.

02

Main entrance system

Accesos y escaleras

La entrada principal se selecciona según la geometría y el layout. A partir de ella, el sistema calcula y genera una escalera capaz de adaptarse a la altura y configuración del edificio.

Less manual work

La lógica detecta una ubicación válida para el acceso y adapta las escaleras al terreno y a la altura del edificio.

03

Window generation system

Ventanas modulares

Un HDA crea variantes desde máscaras alpha personalizadas. Los sockets se distribuyen sobre segmentos válidos de fachada y Unreal instancia automáticamente el modelo seleccionado.

Artist control

La automatización conserva las decisiones creativas: los parámetros permiten elegir variantes, ajustar la distribución y dirigir el resultado desde Unreal Engine.

04

Procedural prop distribution

Multiparm asset system

La distribución de assets expone controles para añadir, ordenar y variar elementos decorativos sin modificar la red interna, acelerando el dressing de cada edificio.

05

Timber framing system

Fachadas conscientes

El sistema clasifica la disposición de las ventanas y selecciona automáticamente un patrón de entramado compatible, evitando intersecciones y manteniendo la coherencia de la fachada.

Todos los sistemas trabajan juntos para producir edificios variados y creíbles, listos para construir entornos de mayor escala en tiempo real.
